# NutriClarté — clickable demo

A single-page, clickable version of the NutriClarté prototype (nutriclarte.ca).

- **Analyze**: up to 3 nutritional goals, simulated barcode scan, score, alerts, Rigid Base (100 g) vs Real Portion slider, ranked alternatives
- **History**, **FAQ**, **About us** (company story and trust), **Support**, **Privacy**, **Contact** (web form + phone number, no `mailto:` links)
- FR / EN / ES language switch in the top-right corner of every page (choice is remembered)

## Run it
Open `index.html` in a browser, or host the repo with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## Edit it
Source lives in `src/` (`app.html` layout and styles, `i18n.js` all text in 3 languages, `app.js` behaviour and demo data). Run `python3 build.py` to regenerate `index.html`.

## Security and privacy
- Strict Content-Security-Policy in `index.html`: only the page's own script runs (pinned by SHA-256 hash, regenerated by `build.py`), no third-party hosts.
- No external fonts, analytics or trackers; system fonts only.
- Everything read back from browser storage is validated before use.
- "Delete all my data" on the History tab erases history, profile and settings from the device.
- The old addresses `/en/`, `/fr/`, `/es/`, `/faq/`, `/support/` and `/privacy/` redirect to the matching page in the app.

## Before going live
- Replace the placeholder phone number (`PHONE` in `src/app.js`) and confirm the location shown on Contact.
- Review the About us story and the Privacy policy (draft copy; have the policy checked against Québec Law 25 / PIPEDA).
- Connect the contact form to a real endpoint (see the comment in `viewContact` in `src/app.js`).
